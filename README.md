# CIMA3D Prosthesis PCB

Este repositorio contiene el codgio central del proyecto CIMA3D para el desarrollo de una prótesis mioeléctrica modular.
Es el codigo creado para la prótesis que contiene una PCB diseñada por el quipo de CIMA3D a lo largo del 2025 al 2027

## Separacion de codigo
El otro proyecto que tenemos es la misma protesis pero no utiliza una PCB sino una placa de topos esta tiene una arquitectura diferente y por eso decidimos separ el proyecto en 2 repositorios
